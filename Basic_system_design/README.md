เคสทดลองออกแบบระบบเครือข่ายร้านกาแฟ (Cafe Network Lab)

โปรเจกต์นี้เป็นการทดลองออกแบบและจำลองระบบเครือข่ายสำหรับร้านกาแฟ เพื่อศึกษาการแบ่งโซนเครือข่ายด้วย VLAN และการจัดสรร IP ให้เหมาะกับการใช้งานจริงตามหลัก Hierarchical Model

---

แนวคิดและเหตุผลในการออกแบบโครงสร้าง (Design Rationales)

1. ทำไมต้องแบ่งเป็น 4 VLAN แทนที่จะรวมเป็นวงเดียว?
- ความปลอดภัยของข้อมูลการเงิน: ร้านกาแฟมีระบบคิดเงิน (POS) ซึ่งหากรวมอยู่ในวงเดียวกับลูกค้าที่เข้ามาใช้ Wi-Fi เสี่ยงต่อการถูกดักจับข้อมูล (Sniffing/Man-in-the-Middle) หรือโดนเจาะระบบ จึงต้องแยก VLAN 30 ออกมาอย่างเด็ดขาด
- จัดการปัญหา Broadcast Storm: การแยก Broadcast Domain ช่วยลดปริมาณแพ็กเก็ตขยะในระบบ ไม่ให้รบกวนอุปกรณ์สำคัญอย่างกล้องวงจรปิดหรือเครื่องพิมพ์ใบเสร็จ
- ควบคุมการเข้าถึงด้วยสิทธิ์ (Zero-Trust เบื้องต้น): ช่วยให้สามารถเขียน Rule/ACL กำหนดให้ลูกค้าใน VLAN 40 ใช้งานได้เฉพาะออกอินเทอร์เน็ตเท่านั้น โดยไม่สามารถสแกนเจอคอมพิวเตอร์แอดมินหรือเครื่องคิดเงิน

2. ทำไมต้องใช้ Router-on-a-Stick (ROAS)?
- ประหยัดงบประมาณฮาร์ดแวร์: สำหรับร้านกาแฟขนาดกลาง การซื้อ Layer 3 Switch ราคาแพงอาจเกินความจำเป็น การใช้ Router ตัวเดียวที่มีพอร์ต Gigabit แล้วทำ Sub-interfaces ผ่านสายเส้นเดียว (Trunk) ลงมาที่สวิตช์ ถือเป็นโซลูชันที่คุ้มค่าและตอบโจทย์ปริมาณ Bandwidth ของร้านได้เพียงพอ

3. ทำไมต้องใช้ Subnetting แบบ VLSM (/27 และ /26)?
- ป้องกันปัญหา IP หมด (IP Exhaustion): โซนลูกค้า (Guest Wi-Fi) มีอุปกรณ์เข้าออกตลอดทั้งวัน จึงขยาย Subnet เป็น /26 เพื่อให้รองรับได้ถึง ~53 เครื่องพร้อมกัน
- จำกัดขอบเขตเครือข่ายภายใน: ฝั่งแอดมิน กล้อง และ POS มีอุปกรณ์ไม่มาก การบีบ Subnet ให้เป็น /27 ช่วยจำกัดขนาดของ Network ลดโอกาสที่เครื่องแปลกปลอมจะเข้ามารับ IP โดยไม่จำเป็น และช่วยให้จำและบริหารจัดการ Range IP ได้ง่ายขึ้น

4. ทำไมต้องแยก Switch 2 ตัว (Distribution Switch และ Access Switch)?
- การจัดการหน้างานจริงและการเดินสาย (Physical Cabling): เคาน์เตอร์คิดเงินและจุดปล่อย Wi-Fi มักอยู่คนละตำแหน่งกับห้องเซิร์ฟเวอร์/ตู้แร็กหลัก การวาง Access Switch เพิ่มที่หน้าเคาน์เตอร์ ช่วยให้เดินสาย LAN เมนเพียงเส้นเดียวจากแร็กหลัก แล้วกระจายต่อเข้า POS และ Access Point ได้ทันที ประหยัดสายและเป็นระเบียบ
- การทำ VLAN Pruning: สวิตช์ตัวล่างดูแลเฉพาะงานหน้าร้าน จึงเซ็ต Trunk ให้ส่งผ่านแค่ VLAN 30 และ 40 ป้องกันไม่ให้ทราฟฟิกของกล้องและออฟฟิศวิ่งลงไปหน้าร้านโดยไม่จำเป็น

---

ภาพรวมไดอะแกรมและบทบาทของแต่ละ Layer

1. WAN Layer (การเชื่อมต่อภายนอก)
- ทำหน้าที่เป็นจุดรับส่งสัญญาณอินเทอร์เน็ตระหว่างผู้ให้บริการ (ISP) เข้ามายังร้าน
- เชื่อมต่อผ่านพอร์ต g0/0 ของ Router
- ใช้สำหรับทดสอบการทำ NAT/PAT เพื่อให้อุปกรณ์ในร้านสามารถออกเน็ตได้ และรองรับการเชื่อมต่อระบบคลาวด์ เช่น ระบบ POS หรือการดูกล้อง CCTV ผ่านแอปจากภายนอก

2. Layer 3 (Routing & Management)
- อุปกรณ์หลักคือ Router ทำหน้าที่เป็น Gateway ควบคุมเส้นทางระหว่างเครือข่าย (Inter-VLAN Routing) ด้วยวิธี Router-on-a-Stick ผ่านพอร์ต g0/1
- แยก Sub-interface ทำหน้าที่แจก IP อัตโนมัติ (DHCP) และเป็น Gateway ให้แต่ละโซน:
  - VLAN 10 (Admin): 192.168.10.1/27
  - VLAN 20 (CCTV): 192.168.20.1/27
  - VLAN 30 (POS): 192.168.30.1/27
  - VLAN 40 (Guest AP): 192.168.40.1/26
- ทำหน้าที่จัดการความปลอดภัย โดยใส่ ACL เพื่อป้องกันไม่ให้ Wi-Fi ลูกค้า (VLAN 40) ข้ามเข้ามาดูข้อมูลในระบบงานออฟฟิศ กล้อง หรือเครื่องคิดเงิน

3. Layer 2 (Switching & Distribution)
- กระจายสายสัญญาณไปยังจุดต่างๆ และแยกทราฟฟิกด้วย VLAN Tagging (802.1Q) แบ่งออกเป็น 2 จุด:
  - สวิตช์ตัวบน (Distribution Switch 16 Port):
    - พอร์ต g0/1 ตั้งเป็น Trunk เชื่อมต่อไปยัง Router (อนุญาต VLAN 10, 20, 30, 40)
    - พอร์ต fa0/1 - 3 ตั้งเป็น Access สำหรับ Admin Zone (VLAN 10)
    - พอร์ต fa0/4 ตั้งเป็น Access จ่ายให้ Switch NVR สำหรับระบบกล้อง (VLAN 20)
    - พอร์ต fa0/5 ตั้งเป็น Trunk ลิงก์ไปยังสวิตช์ตัวล่าง โดยส่งเฉพาะ VLAN 30 และ 40 เพื่อไม่ให้มีข้อมูลที่ไม่จำเป็นวิ่งลงไป
  - สวิตช์ตัวล่าง (Access Switch 16 Port):
    - รับสาย Trunk จาก fa0/5 ของสวิตช์ตัวบน
    - พอร์ต fa0/1 ตั้งเป็น Access ให้ระบบคิดเงิน POS (VLAN 30)
    - พอร์ต fa0/2 ตั้งเป็น Access เชื่อมต่อไปยัง Access Point (VLAN 40)

4. Endpoint Layer (อุปกรณ์ปลายทาง)
- เป็นโซนที่ต่อเข้ากับอุปกรณ์ใช้งานจริง โดยแต่ละกลุ่มจะได้รับ IP จาก DHCP ตามขนาดการใช้งาน:
  - โซนแอดมิน (VLAN 10): คอมพิวเตอร์และพรินเตอร์สำนักงาน ได้รับ IP ช่วง 192.168.10.10 - 30
  - โซนกล้องวงจรปิด (VLAN 20): กล้อง CCTV และเครื่องบันทึก NVR ได้รับ IP ช่วง 192.168.20.10 - 30 (เว้นเลขต้นๆ ไว้ทำ Static IP ให้ตัว NVR)
  - โซนคิดเงิน (VLAN 30): เครื่อง POS จอออเดอร์ และพรินเตอร์ใบเสร็จ ได้รับ IP ช่วง 192.168.30.10 - 30 แยกเพื่อความปลอดภัยของการเงิน
  - โซน Wi-Fi ลูกค้า (VLAN 40): มือถือและแท็บเล็ตของลูกค้าในร้าน ได้รับ IP ช่วง 192.168.40.10 - 62 รองรับได้ประมาณ 53 เครื่องพร้อมกัน

---

สรุปตารางการตั้งค่าพอร์ตและ IP

- VLAN 10: Admin Zone | Switch บน พอร์ต fa0/1-3 (Access) | Gateway: 192.168.10.1/27 | DHCP Pool: 192.168.10.10 - 30
- VLAN 20: NVR POE, CCTV | Switch บน พอร์ต fa0/4 (Access) | Gateway: 192.168.20.1/27 | DHCP Pool: 192.168.20.10 - 30
- VLAN 30: POS Terminal | Switch ล่าง พอร์ต fa0/1 (Access) | Gateway: 192.168.30.1/27 | DHCP Pool: 192.168.30.10 - 30
- VLAN 40: Guest Access Point | Switch ล่าง พอร์ต fa0/2 (Access) | Gateway: 192.168.40.1/26 | DHCP Pool: 192.168.40.10 - 62
- ลิงก์ Switch ตัวบนไป Router: พอร์ต g0/1 (Trunk VLAN 10, 20, 30, 40)
- ลิงก์ Switch ตัวบนไปตัวล่าง: พอร์ต fa0/5 (Trunk VLAN 30, 40)
